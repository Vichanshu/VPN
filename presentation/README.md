# Presentation

Static site, no build step. Open `index.html` in a browser, or serve the folder:

    npx serve .

Keys: left/right arrows move, `N` notes, `O` overview, `D` pen, `H` highlighter, `Esc` stop drawing.
Notes and drawings are saved in the browser. Use Export / Import to keep or move them.
Print (browser print dialog) gives one slide per page.
